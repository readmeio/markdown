# Variables in inline HTML

<span>Inline: <<companyName>></span>

<div><<companyName>></div>

<p><<companyName>></p>

<h3><<companyName>></h3>

<div>{user.companyName}</div>

<p>Plan: {user.planName}</p>

<div>**bold** and <<companyName>></div>

<div style="color: red"><<companyName>></div>

<div>{ color: red }</div>

<div>{1 + 1}</div>
