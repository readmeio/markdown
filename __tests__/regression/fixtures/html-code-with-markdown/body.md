# Markdown inside an html code tag

Backticks inside the tag: <code>`hello`</code>

Inline code between text: <code>a `b` c</code>

Bold inside the tag: <code>**bold**</code> and <code>__bold__</code>

Emphasis inside the tag: <code>*em*</code> and <code>_em_</code>

Escaped backticks stay literal: <code>\`hello\`</code>

Plain inline code still works: `console.log("hi")`

- In a list item: <code>`hello` world</code>
